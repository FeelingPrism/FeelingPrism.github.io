Main Battle Tank

A parametric solid modeling project executed entirely within Year 8 to self-teach the core principles of component architecture and mechanical constraints.

Loading Technical Geometry...
Phase I // Exploration Year 8 // Start

Interface initialization.

To establish a baseline proficiency in modern solid modeling, I initiated this project as a rigorous, self-directed engineering exercise. Having no prior training in Autodesk Fusion 360, the immediate objective was translating physical vehicle design theory into clean, two-dimensional sketch planes. This initial phase involved adapting to the environment's software mechanics, managing user interface properties, and mastering primary extrusion methods to isolate structural mass blocks.

Phase II // Optimization Year 8 // Mid

Constraint infrastructure.

Progressing past simple drafting required a complete structural pivot toward strict parametric constraints. I utilized this phase to master dimensional dependencies, ensuring that variations in core chassis specifications would not cause fatal errors across the timeline. By implementing localized component mapping and mechanical joint linkages, I synchronized the unmanned turret ring assembly with the hull configuration, completely eliminating intersecting solid boundaries.

Phase III // Execution Year 8 // Completed

Production validation.

The final development tier concluded within Year 8, focusing on engineering refinement and ballistic profile integrity. The design optimizes line-of-sight protection thickness across the sloped glacis array and integrates an isolated ammunition mechanical bay. Completing this entire engineering cycle as a standalone exercise successfully established the spatial reasoning and parametric mastery required to tackle advanced aeronautical design challenges.
