Development Sortie

Project Timeline

Documenting the evolution from proprietary constraints to a decoupled, high-performance architecture.

Phase 01 // Discovery

IONOS CMS Deployment

Initial build using IONOS Website Builder. Identified critical limitations: proprietary software locks blocked custom Tailwind CSS injection and third-party API integration. The environment was deemed unfit for professional engineering requirements.

Phase 02 // Re-Engineering

DNS Migration & Decoupling

Strategically decoupled the domain from IONOS hosting. Reconfigured A-Records and CNAME to point toward GitHub's distributed servers. This enabled full autonomy over the codebase.

Phase 03 // Production

Tailwind & AJAX Integration

Developed a custom UI using a Bento Grid architecture. Engineered an asynchronous data pipeline using the Fetch API to handle contact submissions without browser redirects.
