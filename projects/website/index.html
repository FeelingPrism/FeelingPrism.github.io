My Website

A timeline of the devlopment of my website as a space for my portfolio to what your seeing right now.

IONOS Essential Jan 2026

The start.

I had bought this website to create a digital portfolio on an IONOS Essential Plan which forced me to use the proprietary editor. To me who had no experience of website building, had thought this was enough to properly build a website. But, as the website grew, I had realised I was locked behind expensive paywalls to give me more design freedom which I desperately needed. I had continued to build upon this website for months after launching it to expand the website and making its UI better but had been met with such horrible constraints that it had caused me to search for alternate methods to design my website

Phase 02: Infrastructure Pivot April 2026

DNS Rerouting

Decoupled domain from IONOS hosting. Reconfigured A-Records and CNAME pointers to GitHub Pages. Established Git-based version control for a continuous deployment (CI/CD) workflow.

Phase 03: System Integration Present

AJAX & Frontend Engineering

Implemented custom Tailwind utility classes. Engineered an asynchronous Fetch API pipeline for Web3Forms, enabling zero-refresh contact submissions and optimized asset delivery.
