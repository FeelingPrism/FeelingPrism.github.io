My Website

A timeline of the development of my website as a space for my portfolio to what you're seeing right now.

IONOS Essential Jan 2026

The start.

I bought this website to create a digital portfolio on an IONOS Essential Plan which forced me to use the proprietary editor. As someone with no prior experience in website building, I initially thought this would suffice. However, as the site grew, I realized I was locked behind expensive paywalls that restricted the design freedom I needed. After months of attempting to improve the UI under these constraints, I began researching alternative hosting and deployment methods. You can view the legacy version of the site at: https://n1920791.websitebuilder.online/

Infrastructure April 2026

DNS Rerouting

As project complexity increased alongside my mock exams, I transitioned to a custom infrastructure by using DNS Rerouting to host the domain on GitHub. I reconfigured the A-Records to point to GitHub's apex IP addresses and established a CNAME alias for the www subdomain. This decoupled the domain from IONOS and allowed me to use a GitHub Repository for version control and rapid deployment of custom CSS, making the UI far more integrated.

Current Website Design Present

Present.

To optimize my development workflow, I utilized AI as a technical co-pilot for rapid syntax implementation. This allowed me to focus on the high-level UI/UX design and information architecture while maintaining my academic standards. I also integrated Web3Forms for the contact section, replacing Formspree to ensure a seamless user experience that doesn't redirect away from my site's design scheme. Repository: https://github.com/FeelingPrism/FeelingPrism.github.io
