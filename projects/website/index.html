My Website

A timeline of the development of my website as a space for my portfolio to what you're seeing right now.

IONOS Essential Jan 2026

The start.

I had bought this website to create a digital portfolio on an IONOS Essential Plan which forced me to use the proprietary editor. To me who had no experience of website building prior to this, had thought this was enough to properly build a website. But, as the website grew, I had realised I was locked behind expensive paywalls to give me more design freedom which I desperately needed. I had continued to build upon this website for months after launching it to expand the website and making its UI better but had been met with such horrible constraints that it had caused me to search for alternate methods to design my website. You can View the old version of the website at:Legacy Site

Infrastructure April 2026

DNS Rerouting

To rapidly develop this website to optimise my workflow, I had utilised AI as a development tool to code for me to save time and focus on the entire UI and design of the website along with all the information and focus on academics and other activities. Furthermore, to help anyone contact me, I had added a contact me section using Web3Forms to allow people to send messages via the website itself. Previously, I had tried Formspree but had switched to Web3Forms as Formspree forced users to go onto a Formspree link saying form sent which affected the UX as it did not match the scheme of my website. You can find my GitHub repository at:GitHub Repository

Current Website Design Present

Present.

To optimize my development workflow, I utilized AI as a technical co-pilot for rapid syntax implementation. This allowed me to focus on the high-level UI/UX design and information architecture while maintaining my academic standards. I also integrated Web3Forms for the contact section, replacing Formspree to ensure a seamless user experience that doesn't redirect away from my site's design scheme. Repository: GitHub Repo
